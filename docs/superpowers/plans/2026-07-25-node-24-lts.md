# Node 24 LTS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make local development and Cloudflare Pages preview builds consistently use Node.js 24 LTS.

**Architecture:** Keep Cloudflare's existing `.nvmrc` discovery path and pin it to Node `24.18.0`. Mirror the supported major in npm package metadata so incompatible runtimes fail before dependency installation.

**Tech Stack:** Node.js 24 LTS, npm, Cloudflare Pages

## Global Constraints

- `.nvmrc` must contain exactly `24.18.0`.
- The root npm engine range must be exactly `>=24 <25`.
- Application code and dependency versions must remain unchanged.

---

### Task 1: Standardize the repository runtime

**Files:**
- Modify: `.nvmrc`
- Modify: `package.json`
- Modify: `package-lock.json`

**Interfaces:**
- Consumes: Cloudflare Pages runtime selection through `.nvmrc`.
- Produces: An exact Node runtime pin and matching npm engine metadata.

- [ ] **Step 1: Run a failing configuration assertion**

Run:

```bash
node -e "const fs=require('node:fs'); const pkg=JSON.parse(fs.readFileSync('package.json')); const lock=JSON.parse(fs.readFileSync('package-lock.json')); const ok=fs.readFileSync('.nvmrc','utf8').trim()==='24.18.0' && pkg.engines?.node==='>=24 <25' && lock.packages?.['']?.engines?.node==='>=24 <25'; process.exit(ok ? 0 : 1)"
```

Expected: exit code `1` because the repository still pins Node `22.3.0`
and has no root engine declaration.

- [ ] **Step 2: Apply the minimal runtime metadata change**

Set `.nvmrc` to:

```text
24.18.0
```

Add this root field to both `package.json` and the root package metadata in
`package-lock.json`:

```json
"engines": {
  "node": ">=24 <25"
}
```

- [ ] **Step 3: Re-run the configuration assertion**

Run the command from Step 1.

Expected: exit code `0`.

- [ ] **Step 4: Install and verify with the pinned runtime**

Run:

```bash
asdf install nodejs 24.18.0
ASDF_NODEJS_VERSION=24.18.0 node --version
ASDF_NODEJS_VERSION=24.18.0 npm clean-install --progress=false
```

Expected: Node reports `v24.18.0`, and npm installs dependencies without
`EBADENGINE`.

- [ ] **Step 5: Run repository validation**

Run:

```bash
ASDF_NODEJS_VERSION=24.18.0 npm run check
ASDF_NODEJS_VERSION=24.18.0 npm run build
ASDF_NODEJS_VERSION=24.18.0 npm run build-storybook
```

Expected: each command exits successfully. If the application build cannot
reach Notion, report the external dependency separately from the runtime fix.

- [ ] **Step 6: Review and commit**

Run:

```bash
git diff --check
git diff -- .nvmrc package.json package-lock.json
git add .nvmrc package.json package-lock.json
git commit -m "use Node 24 LTS"
```
